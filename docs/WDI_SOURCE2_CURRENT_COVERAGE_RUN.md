# WDI Source 2 fiscal coverage rerun

This branch exists only to rerun the existing no-write World Bank WDI Source 2 fiscal coverage proof against current upstream data.

The audit keeps central-government debt, public/publicly-guaranteed external debt service, external debt, fiscal capacity and fiscal balance as separate concepts. It does not change production scoring, source activation, country payability, peer thresholds, freshness thresholds or the Base mainnet gate.

Any production promotion requires exact measured coverage, source rights, a versioned methodology, deterministic adapter/shadow evidence and a new global production census.
