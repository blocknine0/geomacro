# Geomacro Testnet API v1.2

This document applies only to the Geomacro Testnet environment. It does not define mainnet or production pricing.

The Testnet quota remains fixed at 500 credits. The Testnet reference rate is 0.5 Testnet USDC per credit, for a fixed 250 Testnet USDC quota. Testnet settlement is non-revenue.

Developer credentials are issued as a paired API Key and API Secret. Plaintext credential values are shown only at creation time and must not be persisted by Geomacro.
