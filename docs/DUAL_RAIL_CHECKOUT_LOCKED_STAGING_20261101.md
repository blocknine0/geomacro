# GeoMacro Dual-Rail Checkout — Locked Website Staging (1 November 2026)

## Deployment intent

This change stages a real pricing-page selection flow and stable payment API paths **without activating payments**. Production funds, wallet instructions, PayPal Orders-v2 capture, credit grants, and entitlement changes remain forbidden.

### User-facing Store UI

- All six canonical products: $9/1,000, $29/5,000, $99/25,000 credits per 30-day prepaid plan; $5/100, $15/500, $30/1,500 one-time credit packs.
- Each product opens a two-tab preview: PayPal/card for eligible international fiat checkout, or native USDC on Base / Polygon.
- QR code, address transfer instructions, wallet execution, PayPal SDK approval and instant-balance success are **absent until live authorization and exact settlement validation**.
- Monthly access requires manual renewal; no PayPal subscription recurring billing is offered.
- The old card-to-USDC promise has been removed. PayPal India pays to the linked Indian bank in fiat, not to a crypto wallet.
- PayPal merchant verification, KYC, international-buyer/card eligibility and domestic-PayPal restrictions are disclosed.

### Public API staging contract

- GET geomacro.live /api/v1/payments/crypto/quote: non-payable SKU/network discovery.
- POST geomacro.live /api/v1/payments/crypto/quote: validates SKU/network against the server catalog and returns **HTTP 423 Locked**. No quote ID, expiration timestamp, receiving address or payment URI.
- POST geomacro.live /api/v1/payments/crypto/verify: **HTTP 423 Locked**, cannot grant credits or accept a transaction hash as attribution.
- POST geomacro.live /api/v1/payments/paypal/create-order: **HTTP 423 Locked** (no provider request).
- POST geomacro.live /api/v1/payments/paypal/capture-order: **HTTP 423 Locked** (no provider request).
- Existing GET /api/v1/payments/paypal and /api/v1/payments/networks remain unchanged.
- No new backend payment-authorization environment flag was added; this iteration is fail-closed even if an old flag is accidentally changed.
- The new routeTree is generated by the existing TanStack Start build plugin; do not manually edit generated route tree.
