# GOAT × Geomacro 60–90 Second Commercial Demo Script

Purpose: show GOAT that x402 is attached to a real machine-purchasable intelligence product, not just a payment test.

## Scene 1 — Agent request

On screen: autonomous treasury / financial agent requests a country or corridor risk preflight from Geomacro.

Voice:

"This agent needs geopolitical and macro risk context before making its own financial decision. It requests a structured Geomacro risk preflight."

## Scene 2 — HTTP 402

On screen: Geomacro endpoint returns HTTP 402 with the GOAT payment challenge and bounded product metadata.

Voice:

"Geomacro does not release the paid intelligence yet. The endpoint returns a GOAT x402 payment challenge."

## Scene 3 — Policy and spend check

On screen: agent checks price, network/token, request ID and its configured spend limit.

Voice:

"Before any payment, the agent checks the price and its own spending policy. The buyer remains in control of payment execution."

## Scene 4 — Merchant verification

On screen: server-side GOAT merchant order verification and exact order/payer/chain/token/amount reconciliation.

Voice:

"After payment, Geomacro does not trust the browser or a client-side success message. It verifies the GOAT merchant state server-side and reconciles the exact order details."

## Scene 5 — Intelligence release

On screen: machine-readable Risk Object appears with score, confidence, evidence references, hashes and Risk Gate output.

Voice:

"Only after verification does Geomacro release the signed machine-readable Risk Object and Risk Gate decision context."

## Scene 6 — Agent use

On screen: agent consumes the Risk Gate result, such as ALLOW / REVIEW / BLOCK, while `execution_authorized=false` remains visible.

Voice:

"The agent can use this as an external decision input. Geomacro provides risk context, but it never authorizes or executes the buyer's financial action."

## Closing

On screen:

- GOAT x402
- Geomacro Risk Intelligence
- Testnet3 acceptance dashboard
- 20 windows × 250 cases = 5,000-case target
- Mainnet merchant review requested

Voice:

"This is the commercial path we want to take to Mainnet: autonomous agents paying for verifiable geopolitical and macro risk intelligence on demand."
