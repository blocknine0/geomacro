## Two audience-specific demos

### Researcher / analyst — public read, no payment

1. Visit the homepage, open Intelligence and navigate among Geopolitics, Macro/FX and Critical Minerals.
2. Inspect the real original-publication date, current/degraded label and coverage notices. Do **not** invent a story for a category with zero eligible current items.
3. Show a genuine available country/topic observation and the concise context; clearly explain that an unscored Find is not a signed risk score.
4. Open Risk Indices and distinguish previously verified historical values from unavailable or current signed numerical scores.
5. End with feedback/contact CTA, not a promised paid response or unsupported country guarantee.

**Acceptance:** URLs work on mobile and desktop; no unresolved “LIVE” badge mismatch; exposed data contains no private original URLs/publisher identity, secret material or internal ingestion status.

### Developer / AI agent — no-funds capability discovery

1. Read the published `/.well-known/geomacro-agent.json`, `/.well-known/geomacro-commerce.json`, and `/llms.txt`.
2. Discover the actual canonical offer IDs, exact prices, limits and request schemas from the current public API setup view. Do not hardcode marketing copy as the authority for prices.
3. Send one **no-funds availability/preparation** request for the exact country/topic/scope using the advertised contract, and inspect whether it has genuine qualified data.
4. On unqualified data, demonstrate a bounded unavailable response with no charge and no false signed/current claim.
5. Signed-object and actual paid-response examples may be shown **only after** independently accepted production proof. Never simulate a real purchase and call it production.

**Acceptance:** exact request-to-evidence linkage, content bounds, provenance-privacy and price entitlement verified. No real USDC transactions in demo.
