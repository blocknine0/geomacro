# Minimum free production mode - honest no-funds health (2026-10-21)

Scope: Geomacro's already functioning **free**, 72-hour Cloudflare D1-derived newsroom.
This adds a distinct, minimal outside-in website acceptance without weakening the
separate, still-red scored Intelligence/GRI/Risk Indices production health.

## Lowest settings in force
- Exactly the existing GitHub Actions and Cloudflare D1 + existing first-party
  source publisher. **No new cloud service, Supabase, B2 operation or billable API.**
- One genuinely dated, approved first-party original is sufficient for the
  **free derived website service**, provided it survives its original publication
  clock, 15-minute release delay, 72-hour retention and source-privacy checks.
- **One original is never enough to assert that all three categories have
  current news.** Report per-category original counts independently.
- Hourly official-source collection and D1 missed-job backstop remain unchanged.
  New lightweight acceptance: 12 best-effort read-only probes per day.
- Test exact main SHA as actually published at geomacro.live, live D1-derived
  story metadata and the same story in the first HTML of /intelligence.
- All observations remain unscored, unpaid, and no raw article/title/URL
  is redisclosed. No CDP key or wallet required.

## Evidence and failure semantics
Run the new `Minimum Free Derived Production Health (No Funds)` action.
Its independent receipt has
`schema=geomacro.minimum-free-production-health.v1`,
`free_derived_ssr_ready`, `derived_rows`, and explicit counts per category.
If all three domains have recent originals the receipt says so; if only one
does, it **never** says all three are current.

The new workflow DOES NOT assert or replace:
- `GET /api/health?deep=1`: strict signed B2/D1/GRI/Risk Indices; HTTP 503
  remains correct while genuine signed proofs absent.
- `GET /api/health?deep=1&profile=live-structured`: separate real-time
  provider-read test for all three unscored category adapters.
- Paid x402 rights/settlement, independently signed numerical scoring,
  country-specific coverage, GRO or 195-country news freshness.

The existing P0 #2046 and #2124 remain open. A genuine fix for their 503
still needs approved current signed Intelligence and reviewed GRI inputs,
separate category certificates, real hash-pinned B2/D1 proof readback,
Risk Indices current-parent promotion and independently green production
health. This monitor cannot synthesize those external approvals or data.
