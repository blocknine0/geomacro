# Per-country real commercial Store preflight from one USGS 2026 original

## Motivation
The 195-country USGS hash-pinned CC0 country/commodity census measured 76 ISO3 countries with genuinely comparable 2024/2025 annual critical-mineral production pairs (316 series). Data presence is not canonical customer entitlement, a real product quote, a signed current event, or a settled sale.

The already-live daily `First qualified country digest (no funds)` performs a legitimate no-payment 0.02 USDC CHN structural country-digest preparation. This step now **also samples three other actual-source-positive countries**, AUS, IND and USA, through the **exact same Store** source rights, canonical availability and structured customer-response assembly modules. Each runs within the original verified MCS release process and reuses its 10-minute memory cache. No additional original CSV provider fetch, cron, subscription, wallet or archive writes are introduced. Depending on existing Store implementation, each separate country may perform its own bounded source-context and D1/B2 reads; this is NOT a statement of zero additional reads.

## Data contract
`mcs_canonical_store_no_funds_country_samples` in the *private/sanitized* existing receipt has three exact ISO3 rows. Each remains one of:
- `PREPARED_SOURCE_ELIGIBLE_NO_FUNDS`: canonical country query plan, actual country-scoped source-rights contract for the EXACT pinned USGS MCS dataset, native annual source observation, Store AVAILABLE, and assembled valid no-execution customer-response hash.
- `NO_COMPARABLE_SOURCE`: USGS original CSV lacks a valid comparable 2024+2025 country production pair, despite a country route existing.
- `CANONICAL_STORE_UNAVAILABLE`: a required Store module, rights, data native period, derived structured response or retrieval condition failed. No claim about a specific reason is invented without an additional authenticated drilldown.
- `ALREADY_SELECTED_COUNTRY_PROVEN`: in the protected manual country path, this selected country already passed the primary exact-byte verification.

The content-only evidence lives in the existing PR/scheduled proof artifact. It holds **no raw USGS data, original upstream URL, token, payment signature or private customer bytes**; only ISO3, status, SHA256 of successfully prepared canonical JSON and explicit nonpaid/non-delivered flags. No buyer transaction or charge occurs, including when Store availability is true.

The existing CHN selection and main protected schedule stay fixed, as do amount 20000 USDC atomic units, D1/B2 quotas, source rights, signing and PREDGE.

## Acceptance and limits
- PR and next delivered main source job must really fetch and verify the publisher's original SHA/CC0 rights, run all real three-country samples, require at least one prepared sample without funds and preserve CHN exact customer bytes acceptance.
- Each successful sampled ISO3 is ONE verified *data-preparation candidate*; it is not one actual paid customer. The other measured 73+ MCS data-positive countries still require exact Store checks, and all 119 USGS-data-negative countries need independent actual evidence for any mineral structural product.
- Mainnet x402 requires owner-authorized merchant custody, eligible rights at request-time, a genuine external buyer payment and separately verified structured JSON readback. This project does NOT override price, entitlement, commercial rights, third-party source policy, signed GRO or PREDGE.
