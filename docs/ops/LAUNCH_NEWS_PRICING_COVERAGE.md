# Launch news coverage and pricing

The Store is the single visible price schedule. API & Agents describes outputs
and links to that schedule. Category aliases share one intelligence-query price;
news volume and the number of feeds do not create category surcharges.

## Required news types

| Category | Event coverage needed |
| --- | --- |
| Geopolitics | Wars/escalation, ceasefires, sanctions/export controls, elections/coups, displacement, border/airspace disruption, cyber/telecom/cable failures, legal/regulatory shocks, investment screening, expropriation, technology controls and disinformation |
| Macro Economics | Rates and central-bank surprises, inflation/jobs/growth, FX/capital controls, fiscal/debt/default, banks/payments, energy/food, shipping/freight/ports/customs, grid/climate/labour shocks, war-risk insurance, Gold/Silver demand/supply/positioning |
| Critical Minerals | Mining/permitting/production, smelting/refining/separation, export restrictions, strategic-material shortages and supply-chain disruptions; retain explicit material evidence. Gold/Silver bullion remains Macro. |

`launch-news-coverage.ts` routes every reviewed hot-topic family to ingestion.
Existing native-language matchers are retained. Topic matching remains discovery,
never corroboration, attribution of event country, scoring or commercial rights.

Three malformed/redundant Google index searches are replaced in their existing
slots by global war/security, macro/corridor and mineral-supply watches. They run
first in the existing private collector, with no extra source slots, D1 tables,
network allowance or paid feed. Country rotation and the <=512 endpoint limit
remain unchanged. Index timestamps are never promoted to original-page time;
index-only watches cannot trigger original-page publication callbacks. Official
issuer fastlane and independent regional publishers remain the confirmation paths.

Five-minute official ingestion and 15-minute private discovery are engineering
targets subject to quota, transport and GitHub scheduling, not guaranteed latency.
Freshness must be measured from actual native publication, intake acknowledgement
and category checkpoint clocks. A healthy quiet feed is not a new event.

## Price-to-evidence boundary

| Public product | Published USDC variants | Required deliverable evidence |
| --- | --- | --- |
| Country digest / profile | 0.02 / 0.03 | Requested-country structural modules with original evidence dates and coverage limits; recent event claims need separately dated evidence |
| Corridor digest / profile | 0.05 / 0.08 | Both directional endpoints and required structural modules; route references alone do not prove physical route disruption or measured flow |
| Intelligence query | 0.05 focused, 0.10 standard, 0.15 complex | Exact query scope, current event/structural evidence as required, eligible rights and matching governed complexity; more headlines alone do not justify a higher tier |
| Signed Risk Object | 0.05 existing, 0.10 newly qualified | Exact independently verified signature, subject, content, issuance and expiry |
| Risk Gate bundle | 0.10 existing-proof preflight, 0.15 standard, 0.25 complex | Qualified signed object included once plus bounded advisory result; customer retains execution control |

The canonical pricing catalog and existing per-request data/rights/signature
preflight remain authoritative. The public discovery response exposes the news
policy explicitly as targets, never as verified live coverage. Neither these
changes nor a feed observation activates checkout, payments or a right to resell
publisher content. A missing required proof remains unavailable, not chargeable.

## Regression locks

- All 36 reviewed taxonomy families must have intake routing.
- Three priority watches replace exactly three existing endpoints and preserve
  country routing and source caps; no raw titles or verified-source claims escape.
- Cyber/telecom, payment, corridor/insurance and mineral shocks pass real collector
  tests with native dated fixtures; bullion never becomes a rare-earth event.
- Store renders each canonical capability/variant price once; API compact output
  renders product descriptions and a pricing link with zero repeated price rows.
- Existing commercial eligibility, immutable price classification, current-data
  proof, source rights, Predge contract and customer-control tests remain intact.

## Global officials and economic-release extension
Formal roles and stable institutions, rather than an unchecked current-leader
name list, match market-relevant government and central-bank communications.
Private statement tags remain extracted claims, never authenticated quotations
or measured market reactions. The official Fed speech feed is now polled every
admitted 5-minute slot (and existing release-window polling), still within the
nine-source macro cap; its pinned host/path and native clocks remain mandatory.

Global CPI/PPI/PMI/GDP/PCE, jobs, retail sales, industrial production, fiscal/debt,
reserves/FX intervention, banking liquidity/deposits/credit/stability, trade
agreements/tariffs/export controls and Hormuz/Red Sea/Suez shipping disruptions
join the shared macro filters and existing priority discovery queries. Existing
195-country official-source routing and first-party issuers supply confirmation;
registration/search results cannot certify every country's live coverage. This
extension does not add paid wires, live exchange quotes, assumed consensus or
causal price-impact assertions.

Every one of the 195 canonical country routes now explicitly searches the same
macro release families (not merely a few economy keywords), while preserving
war/mineral discovery terms. The existing 25 index-country slots plus 24 local
publisher slots per tick are unchanged: all 195 country searches occur over
eight delivered 15-minute slots, nominally 120 minutes, alongside continuously
polled publisher sources. This is a rotation target, not fresh-event coverage
for every country. Country queries never assign an event country, create a
national central bank for currency-union members, or fabricate absent data
(such as the already recorded missing Vatican statistics source).

Production retention repair: every OSINT website write run performs one admitted
empty sweep after all nonempty chunks and before complete readback. An already
601+ baseline repairs once only after the reader proves that exact condition;
unknown outages/quota failures cannot trigger speculative cleanup. This prevents
a healthy new source observation from leaving the shared journal unavailable.


## Country critical-mineral development coverage
All 195 existing country discovery queries explicitly include material and
lifecycle anchors: critical raw materials, rare earths and magnet materials;
lithium, copper, cobalt, nickel, graphite, gallium, germanium, antimony,
tungsten, manganese, vanadium and bauxite; mine permits/closures, processing,
smelter outages, mineral exports, royalties, recycling, reserves, offtake and
investment. Existing multilingual publisher filters and global mineral priority
watch continue alongside this country rotation. Gold/silver stay under Macro.

This expands query content within the existing requests, not the source count,
D1 allowance or paid contract. The 25 country slots per delivered 15-minute run
cover 195 country routes in eight slots (nominal 120 minutes). Global priority
and publisher discovery target 15-minute runs; delayed schedules, source failures
and quota admission can lengthen actual intake. Every-country timely original
publication coverage is not asserted. Index-only alternatives remain unverified
discovery with native-date, rights and delivery gates unchanged. Query country
never supplies event attribution. No development is invented for a country with
no qualifying release. Shared-journal projection into the existing Predge feed
retains the existing category and authentication contract.
