## When this workflow should HOLD

- Any upstream D1/B2 quota exhausted or stale/unknown provider metrics.
- A missing migration index, Time Travel bookmark, P1 bundled lease table or protected D1 binding.
- Candidate version metadata lacks the current main SHA, verified HOT50/P1 flags, exact same signer and binding names/types.
- Live candidate `/health` SHA mismatch, public decision key change, unauthorized protected write not returning 401.
- Any Cloudflare deployment splitting the wrong versions or percentages.
- Current certified Risk Indices or GRO cells missing: **keep product not ready, do not fabricate signed evidence**.

**No additional daily reserve is created:** a safe pause is a legitimate outcome when the owner-enforced 140k per UTC day limit is already exceeded. The producer may continue source polling and encrypted holding within existing policy, but GitHub short-retention artifacts alone are not B2/R2 physical durability.
