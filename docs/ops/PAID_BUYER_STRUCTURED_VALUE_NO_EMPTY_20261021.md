## Automatic purchase flow (buyer must actually receive the correct data)
1. Parse exact buyer country or corridor, category, query plan and requested modules; reject unsupported combinations before payment.
2. Independently check current native-dated original evidence, licensed derived-use rights, required modules and signed authority when applicable.
3. Assemble the real Geomacro-owned structured JSON BEFORE issuing any payment challenge. The new final buyer-value gate verifies each actual requested subject has its matching structural module, nonempty and genuinely dated observations or governed state; rejects empty, wrong-country, missing-module or wrong-price output.
4. Apply existing raw news/source leakage checks, response schema and product hash. Freeze canonical answer bytes in the existing authenticated Durable Object, read back twice, bind SHA256 to a precise catalog price, network, asset and merchant address.
5. Return x402 HTTP 402 only AFTER the eligible output is already frozen. Buyer authorizes once. Recheck valid rights/freshness and signed expiry, claim idempotently, verify and settle once, then deliver the EXACT frozen JSON HTTP bytes.
6. A paid buyer retry retrieves exactly the recorded delivered bytes, never refetches/rebuilds or charges again. Ambiguous payment result is held for reconciliation.
