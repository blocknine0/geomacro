# Ask Geomacro reuses canonical three-domain free originals

The ordinary "latest geopolitics", "latest macro/FX", "latest rare earth"
and bare "latest news" Ask questions now consult the SAME previously
qualified, native-dated 72-hour D1 journal used by the public website and
free machine API, **before** contacting any original publisher.

A source-neutral unscored publication within 24 hours can be reused across
Ask, Website and free API without re-fetching the upstream original.
Category IDs and independently checked topic relevance remain distinct;
one original is never extra corroboration. Where a category lacks suitable
journal evidence, Ask queries only that missing category using existing
bounded first-party readers. A D1 outage does not imply no news globally.
Records demanding publisher attribution are not silently made anonymous.
Historic annual statistical reference, signed GRO/GRI, country/asset risk
questions and payable x402 orders use their original independent gates.

This does not put raw upstream data in D1, B2, logs, responses or prompts.
No GRI score, billing, source licenses, Supabase or funding changes.
