# Automatic original verification for every incoming Intelligence item

The existing five-minute fastlane and hourly continuity publisher retain
private source references for the signed D1 newsroom. Their credential-separated
LOW reviewer checks the retained journal after ingestion, including pending
items from earlier runs. No new cron, paid provider, B2 request or Supabase is
introduced.

The source-page checker recognizes the existing category-bound newsroom
publisher IDs and reuses the canonical global-feed article pins. Treasury,
DBT, Energy and other GOV.UK references no longer have to impersonate FCDO.
This source-reference path is distinct from commercial independent-issuer
verification and never expands those commercial pins.

Pending items retain their original signed queue time when deferred without
a page attempt. The reviewer chooses older waiting items before later arrivals,
with category turns and the existing per-host cap. A valid current verified
result is reused; an actual rejected read keeps its existing retry cooldown.
Invalid, expired or altered previous signatures cannot suppress a new check.
Reference reconciliation covers all bounded collector candidates, including
those beyond the former 1000-item truncation.

HTML and any pinned first-party publication-clock API request consume the
same four normal network slots; the existing two reserved slots remain unused.
Every attempt still requires the exact HTTPS article path, native publication
clock, valid body/MIME and actual HTML-byte hash. Redirects, off-host URLs,
modified/retrieval timestamps, forged source IDs, wrong categories and rights
or payment assertions cannot supply a source-page proof.

Every retained item receives an explicit verified, pending or rejected result.
Missing references, date-only originals, publisher denial, unsupported routes,
quota deferral or an expired original remain visible. A busy or inaccessible
publisher cannot be guaranteed immediate verification within free quotas.
The source verification window remains 22 hours and the journal remains 72
hours; expiry never changes the original source date.

`SOURCE_EVIDENCE_VERIFIED` means only original-page bytes and native publication
time were checked by the separate automated LOW authority. Semantic factual
review, independent corroboration, commercial rights, GRI certification and
x402 billability are not granted by this label. Existing commercial validators
remain mandatory and unchanged.
