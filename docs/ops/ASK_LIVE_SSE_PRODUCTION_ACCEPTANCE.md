# Ask live-readback verification (no funds)

The source-separated Ask v2 SSE endpoint must answer at least one exact officially fetched **annual** WDI question, show an original reporting year and World Bank attribution, preserve source secrecy and fail closed on missing evidence. A narrow read-only GitHub Actions workflow runs outside-in after publication and periodically. Passing CI on mocked responses is not a live readback. The probe does NOT call payment endpoints, does NOT issue signed risk objects and does NOT imply fresh scored Intelligence/GRI/Risk Indices. The existing strict three-domain signed/index acceptance remains separately tracked and must not be relaxed to compensate for stale hot snapshots. When live deployment is stale/missing, this acceptance intentionally fails.
