# Question-driven original retrieval for public Ask (2026-10-17)

This scoped release integrates the existing canonical 195-country registry, country/topic-restricted on-demand discovery and the existing first-party original-article timestamp verifier directly into Ask Geomacro. Each selected original is passed through the existing safe derived-signal model. A 15-minute public release delay and 24-hour / bounded user-requested window remain in force.

Provider calls use fixed ISO3/domain/topic identifiers, not private user questions. Article headlines, upstream URLs, publisher identities and payloads stay private. This is an unscored original-release observation and never a same-event corroboration, numerical outcome, country risk score, commercial rights certificate, signed GRO or x402 payment.

Index-only fallback is insufficient_evidence=true even when a model formats indexed leads. No paid-provider purchase, Supabase write, new risk engine, pricing modification or website presentation change.

Limitations: exact present-day numerical statistics and full semantic multi-turn reasoning are not added by this PR; website and country-category availability depend on real publishers; original page verification can find zero eligible results. Green CI is not a live deploy attestation.
