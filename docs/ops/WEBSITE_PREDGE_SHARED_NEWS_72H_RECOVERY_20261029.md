# Website Intelligence → canonical D1 → Predge: shared 72h recovery

Scope: GeoMacro-owned source publishing only. PREDGE Worker route, token, D1 500/day quota, 90-day pilot, attribution, paid GRO, Risk Gate and credentials remain unchanged. This makes the retained **eligible 72h news journal** a common publication source. It does not make every browser on-demand observation, private raw/source data, old static history or unqualified item part of the partner contract.

When the shared D1 Free quota governor denies source intake, the existing hourly Website Derived News Continuity schedule now executes **archive-only collection**: official-derived validation and append-only static archive publication, without an authorized Worker write, B2 signer, Supabase, payments or root bearer. There is no separate schedule, queue, store or D1 load. Its candidate JSON is the existing exact archival format. Missing source checks and archive publish errors fail the job, not silently count as delivery.

On the next governor-admitted run, the existing publisher writes current original-derived signals, publishes the append-only archive, and then runs the new bounded archive→D1 reconciliation:
- Read only source-native 72h eligible signals from at most the UTC months overlapping the last five days, three category shards each, with strict HTTP/file/schema and existing original validation.
- One complete D1 journal read before replay, idempotent ID deduplication, reject ID collisions and differing canonical/archival revisions; refuse a 601st candidate; use existing authenticated <=40-row and <64KiB ingestion batches.
- Re-read the existing complete D1 journal after replay; fail on any remaining eligible archive ID. Keep old original times/attribution, and never mark a research item as scored, signed or commercially cleared.
- The existing public/Predge shared projection continues to read exactly the canonical D1 journal. The public source-neutral filter may omit credited records; private authenticated Predge projection preserves allowlisted mandatory credits. Unknown credits remain withheld.

**Limitations:** D1 Free budget HELD means newly archived items do not reach the authenticated PREDGE feed until the governor re-admits D1. On-demand publisher checks shown to a browser between scheduled ingestions are not instantly persisted; current source polling is GitHub best effort. After 72 hours, unshared archive entries cannot be backdated and the partner contract does not include historical archival delivery. A changed existing canonical ID cannot safely be overwritten with stale archive prose. Production acceptance must run an admitted real collection with a non-empty archive cohort, successful replay receipt, independent attributed partner journal parity, and partner owner acknowledgement. Do not claim 100% continuous coverage from code CI.
