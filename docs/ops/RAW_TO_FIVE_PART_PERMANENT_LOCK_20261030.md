# GeoMacro permanent raw-evidence → five-part derived intelligence lock

**Canonical path:** existing Geopolitics, Macro/FX, Critical Minerals collectors → immutable original metadata and lawful source content in private canonical D1 → existing governed B2 archival → GeoMacro-authored five-part analysis → question-matched structured JSON for users/machines.

**The raw material is evidence, never the customer-facing product.** Do not return upstream full-text articles, raw feed/HTML, private source identity, credentials or private archive objects as structured answers. Preserve original identity, source-native date/day precision, immutable SHA, deduplication and provenance privately.

For every admitted original in `geopolitics`, `macro`, or `rare_earth`, generate the same five named fields with event-specific content:

1. `what_happened`
2. `why_it_matters`
3. `market_relevance`
4. `what_to_watch`
5. `evidence_and_confidence`

**No separate manual commercial review is a prerequisite for private raw retention or draft structured analysis generation.** News processing remains automatic across all three categories, including records with `commercial_rights_verified=false`. Uncorroborated claims, unobserved market moves and unknown follow-ups must remain explicitly uncertain rather than be invented or standardized into repeated prose.

**Existing sale/delivery controls are unchanged:** a GeoMacro-authored derivative does not automatically erase upstream source usage or attribution restrictions. Eligibility/rights, entitlement, quote, and payment are checked only at the existing chargeable delivery boundary, not used to suppress raw-to-draft transformation. Do not sell/re-distribute upstream raw material or count free drafts as paid delivery. No new provider, model, payment rail, price tier, database, source quota or approval ceremony.

**Code lock:** `PHASE2H_RAW_TO_STRUCTURED_LOCK` in `scripts/lib/phase2h-raw-original-records.mjs`. A strict five-field shape assertion is performed for every generated record, and `scripts/tests/phase2h-raw-news.test.mjs` checks all three categories, native times, private raw boundaries and no-commerce-approval draft generation. Existing private query and public newsroom projections retain their independent safe output contracts.

**PREDGE**, its protected paths, the historical repository/Supabase, frozen website presentation, pricing, x402 and payment authorization stay untouched.

**Acceptance:** merged code and green tests establish the enforced source contract; live readiness still needs real canonical D1/B2 and exact-question readback. No assertion of production completeness, 585-cell source coverage, commercial rights or real USDC settlement follows from an offline test alone.
