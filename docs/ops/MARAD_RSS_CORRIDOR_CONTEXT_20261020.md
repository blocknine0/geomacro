# MARAD official RSS corridor-context reader

The pre-existing `marad_advisories` source family now participates in the single canonical `Free Commercial Source Lineup No-Funds Rotation` workflow at best-effort 30-minute intervals. No additional cron, second MARAD poller, B2/Supabase writer or payment flow is introduced.

- Exact first-party feed: `https://www.maritime.dot.gov/taxonomy/term/441/feed`, linked by MARAD's Maritime Security Communications Industry taxonomy page.
- Private, bounded HTTPS GET through the existing `probeNoKeySource`: max 256 KiB, 7-second timeout, no redirects, and standard 401/403/429 backoff.
- Native `pubDate` must have an explicit supported timezone. Feed/transport clocks, date-only fields and article-modified dates are never invented as issuer publication.
- First-party advisory item URLs are restricted to `https://www.maritime.dot.gov/msci/20YY-NNN[-A]-...`. The item title must begin with the advisory number. Duplicates, unknown publishers, future and older-than-90-day feed items are not route context candidates.
- Candidate route tags: `strait_of_hormuz`, `bab_el_mandeb`, `gulf_of_aden_somali_basin`, `black_sea_grain_kerch`, `suez_canal`. These are canonical existing named-route IDs and keyword candidates, never actual route telemetry or independently verified attacks.
- Fingerprints and broad source status only persist to the existing 3-row D1 checkpoint. New aggregate count and canonical route IDs can appear in the sanitized 3-day operator receipt, without source titles, upstream article links or raw XML.
- Same MARAD maritime system is one publisher family. Multiple advisories/editions do not count as independent corroboration.
- The MARAD article's own advisory status, exact effective/expiry day, publisher original article-page date, and derived commercial rights remain **unverified**. No signed GRO, user-facing new news, GRI score, x402 charge or partner delivery is generated by this change.
- Feed transport might be unavailable on some GitHub runners; the existing collector retains degraded-state receipts rather than reporting false source health.

Tests: `node --test scripts/tests/marad-official-corridor-context.test.mjs scripts/tests/free-source-production-updates.test.mjs`.

Production acceptance: after merge, inspect exact-main `Free Commercial Source Lineup No-Funds Rotation` `read-only-production-mesh` receipt: MARAD source state should be `TRANSPORT_READABLE` and the configured reader count 32. A reachable feed with no new qualified dated items remains legitimate (no fabricated events). The overall source mesh may still be degraded because other providers are restricted.
