# Free global-index original rescue

GDELT DOC remains an external discovery index, never an original publisher or publication clock. An already returned hit may enter private article review only when its exact HTTPS host/path matches an existing approved official feed, requested country/topic/mineral agree, and its canonical issuer URL contains no query, fragment or credential. No additional GDELT request is introduced.

Native issuer candidates retain priority within the existing 16-lead/four-page budgets. Index-only leads do not suppress official publisher fallbacks. Existing request deadlines, global 12-request discovery bound, 401/403/429 circuit and no retries after provider denial remain intact.

Before an index-only hit is page-verified, visible first-party H1 words/numbers must exactly agree with the indexed title (case/punctuation normalized), and genuine precise publication metadata must exist outside script/style/template/comment text. The shared original-date verifier still rejects missing, stale, future or contradictory clocks. No seendate or modified time is substituted. Cross-country or forged headings are denied.

The existing private qualification pipeline receives the candidate; public discovery exposes counts only. Same-event review, rights, scoring, signing and payment remain unverified. No source payload is stored or redistributed, no Supabase/B2 write and no paid/external decision service is added. The optional Jev/TypeSafe proposal from the earlier PR is deferred outside this free-source repair; its former commit remains recorded in PR history.
