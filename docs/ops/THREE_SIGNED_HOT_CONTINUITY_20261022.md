### Production cadence: no local laptop and no additional costly polling

- Existing **GRI v1.2 Genuine Signed Ready Cadence Backstop** checks pre-approved immutable pointer hints four times/hour. Invalid or absent hints stop *before B2 operations*, never self-approve a GRI or commercial rights. Existing reviewer-signed source event dispatch can wake the exact same protected publisher earlier.
- Existing **Risk Indices Verified GRI Parent Repair Backstop** checks a genuinely current signed GRI parent twice/hour and dispatches only a missing/outdated indices child, with one bounded retry. It cannot score GRI.
- Existing **Signed Hot Snapshot Pre-Expiry Guard** reads a single D1 metadata query at 09 and 39 minutes. This PR adds an **early live-source warning at 45 original-source minutes**, leaving 15 nominal minutes before public commercial eligibility's 60-minute maximum. 12h Intelligence / 3h GRI and Indices are *historical signature-validity limits*, **not** permission to call a 75-minute score live.
- The same existing **Production Website Health** acceptance runs after protected publisher completion and checks exact deployed website SHA, current customer hot HTTP 200 and real deep-health HTTP 200.
- GitHub cron scheduling is best effort; it cannot guarantee a bound for release latency. Actual Workers/website must independently enforce expiry at request-time. Never promise 3/3 freshness when no independently approved source exists.

## Deterministic failure handling

| Condition | Machine/operator route | Customer truth |
|---|---|---|
| Facts / Rights proof absent | Acquire approved signed current first-party evidence using separately governed authorities; existing machine publisher refuses unsigned bytes | Unscored free Finds may work; signed Intelligence unavailable |
| Independent GRI reviewer pin absent | Approved independent reviewer configures `GEOMACRO_INDEPENDENT_REVIEW_PUBLIC_KEY_PEM` and separately approved DER SPKI SHA256 in protected `production` environment. Validate distinct identity; never invent reviewer | GRI v1.2 unavailable |
| Signed reviewed GRI input or country-category cert absent | Approved GRI reviewer provides genuine signed current scores and independently verified historical B2 baseline; use existing content-addressed signed-ready dispatch | GRI unavailable, dependent Indices cannot be called current |
| GRI current but Indices missing/stale | Existing verified-parent indices backstop recovers exact child with bounded deduplicated retry | Only GRI may serve current until child success |
| B2 GET/PUT, D1 transport or quota unavailable | Observe existing global B2/D1 quota ledger, reserve protected headroom, retry only with safe backoff; never invent complete readback | Return truthful 503/last dated history; no x402 charge |
| All D1 source metadata apparently fresh | Independently require public signed B2 immutable full-byte hash, D1 payload hash, score/country proofs and production public HTTP 200 on all three | Metadata alone is never 3/3 signed acceptance |

## Strict closure criteria

1. Two separate valid independently governed Facts and Rights sources + actual current approved machine signed package and its immutable SHA/B2 bytes.
2. Independent approved GRI reviewer public-key pin, **real verified signatures** and review inputs; genuine current GRI v1.2 numerical package and country/category certificates; correct historical B2 lineage.
3. Machine/publisher exact-main no-funds job produces Intelligence; reviewed GRI job produces current numerical GRI; child job computes indices from that GRI's actual hash and time; all with no old Supabase.
4. Public intelligence, public GRI and public Risk Indices GETs return three real current signed 200s with exact B2/D1 and original source-clock proofs.
5. `GET https://geomacro.live/api/health?deep=1` returns actual 200 with three current hot products. Website build marker matches canonical deployed code. Owner-authorized x402 settlement remains separate and OFF absent specific funds authorization.

**Until every real test passes, signed 3/3 remains 0/3; an updated workflow, successful free news scrape, or historical database restore is not current signed production.**
