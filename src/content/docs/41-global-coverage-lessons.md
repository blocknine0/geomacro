# 41. Coverage Lessons

The most important coverage rule is simple:

> **Missing evidence is not zero risk.**

A subject can have useful structured macro or geopolitical information while lacking the current evidence required for a particular live output.

Correct behaviour is to expose the limitation:

```text
structured context: available
required live evidence: insufficient
requested verified output: unavailable / degraded
```

Incorrect behaviour is to fabricate a low score because a source failed, a domain is missing or a current event was not observed.

The same principle applies to GRI publication, country/corridor Risk Objects and Risk Gate pre-flight decisions: unsupported or unverifiable state should remain explicit and fail closed at the Geomacro authorization boundary.
