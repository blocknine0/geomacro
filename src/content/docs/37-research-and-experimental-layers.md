# 37. Research and Experimental Layers

Geomacro uses explicit public status labels so implemented capability is not confused with roadmap intent.

The website-wide status vocabulary is:

- **LIVE** — available in the current public product
- **PRIVATE PILOT** — implemented but access and validation are controlled
- **TECHNICAL PROOF** — working secondary/Testnet implementation, not a primary production service
- **PLANNED** — intended or under development, not currently available
- **LEGACY** — older implementation retained for compatibility or evidence

Examples:

| Capability | Status |
|---|---|
| Public Risk Intelligence | LIVE |
| Geopolitical Risk Index | LIVE |
| Macroeconomic Risk Index | LIVE |
| Critical Minerals Risk Index | LIVE |
| Ask Geomacro | LIVE |
| Risk API / Risk Gate | PRIVATE PILOT |
| Prediction markets | TECHNICAL PROOF |
| Arc / CCTP / Bridge & Swap | TECHNICAL PROOF |
| Broad professional/enterprise packaging | PLANNED |

The current public Risk Indices preserve the versioned GRI v1.2 parent methodology and verified proof lineage. Historical combined-GRI snapshots remain versioned audit records rather than a second current headline product.

A roadmap item or experimental implementation must never be presented as generally available solely because code exists.
