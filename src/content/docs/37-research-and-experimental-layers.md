# 37. Research and Experimental Layers

Geomacro uses explicit public status labels so implemented capability is not confused with runtime availability or customer authorization.

The website-wide status vocabulary is:

- **LIVE** — available in the current public product
- **PRIVATE PILOT** — implemented with controlled entitlement and operating scope
- **TECHNICAL PROOF** — working secondary implementation that is not represented as an active production settlement or execution service
- **PLANNED** — intended or under development, not currently available
- **LEGACY** — older implementation retained for compatibility or evidence

Examples:

| Capability | Status |
|---|---|
| Public Risk Intelligence | LIVE |
| Geopolitical Risk Index | LIVE |
| Macroeconomic Risk Index | LIVE |
| Critical Minerals Risk Index | LIVE |
| Ask Geomacro | LIVE |
| Risk API / Risk Gate | PRIVATE PILOT |
| Prediction markets | TECHNICAL PROOF |
| Programmable-finance application layer | TECHNICAL PROOF / RUNTIME-CONTROLLED |
| Broader professional/enterprise packaging | CONTROLLED EXPANSION |

The current public Risk Indices preserve the versioned GRI v1.2 parent methodology and verified proof lineage. Historical combined-GRI snapshots remain versioned audit records rather than a second current headline product.

A roadmap item, configured adapter or experimental implementation must never be presented as active solely because code exists. Runtime contracts and customer scope remain authoritative.
