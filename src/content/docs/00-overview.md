# Geomacro Documentation

Geomacro is geopolitical and macro risk intelligence infrastructure for human and machine decisions.

> **Current status:** Public Risk Intelligence, the Global Risk Index and grounded Ask Geomacro are live product surfaces. Risk Gate and signed machine-delivery interfaces are **Private Pilot**. Arc, Circle, CCTP, Bridge & Swap and prediction-market functionality are **Technical Proof / secondary application layers**.

This documentation separates implemented capability from Private Pilot, technical proof and planned work. It does not imply an independent external security audit, production SLA or institutional deployment unless explicitly stated.

---

## Product hierarchy

1. Risk Intelligence
2. Global Risk Index
3. Ask Geomacro
4. Risk Objects and Risk Gate
5. Data / API and institutional workflows
6. Research and methodology
7. Secondary technical-proof layers

The canonical current Global Risk Index methodology is **gri-v1.2.0**. GRI is an aggregate intelligence signal, not a market probability.
