# 24. Access Levels: Free to Institutional

Geomacro separates public evaluation, professional depth, governed machine delivery and institutional deployment. The payment method does not define the product. The entitlement and current delivery capability do.

## Free Explorer — LIVE

Current public surfaces include:

- Risk Intelligence
- separate Geopolitical, Macroeconomic and Critical Minerals Risk Indices with verification context
- Ask Geomacro
- public research and methodology
- approved public country/corridor views where available
- technical-proof surfaces clearly labelled as Testnet/secondary

Free Explorer is the website/dashboard experience. It does **not** grant a structured API credential, signed Risk Object entitlement or Risk Gate entitlement.

The public Risk Indices preserve the audited GRI v1.2 parent methodology and proof lineage. Historical combined-GRI snapshots remain audit records rather than a second live headline product.

## Pay per call — PRE-LAUNCH MAINNET

Geomacro has prepared a pay-per-call machine product for AI agents and automated workflows.

Canonical product: `geomacro_adaptive_risk_intelligence_v1`.

- Free deliverability check: `POST /api/x402/risk/availability`
- Prepared Coinbase-compatible paid resource: `POST /api/x402/intelligence`
- Prepared production price: **0.02 USDC per successful paid call**
- Static documentation pricing is informational. When production is enabled, the live HTTP 402 challenge or approved provider plan is authoritative.
- A request that cannot currently be delivered is not chargeable.
- Payment/query binding, replay protection, idempotent delivery and duplicate-charge protections remain part of the commercial path.
- Production real-money activation remains disabled until the coordinated launch gates and explicit owner authorization are complete.

Pay-per-call access is designed for software that needs occasional governed intelligence without first taking a monthly subscription.

## Professional intelligence — FOUNDING PILOT

Current controlled professional packaging uses a **5,000-credit / 30-day** starting pool.

It can include:

- deeper analytics and historical context;
- change attribution;
- governed country/corridor views;
- agreed structured exports where scoped;
- professional research workflows without downstream execution custody.

Pilot terms, permitted use and support scope are agreed before activation. This is not yet anonymous self-serve general availability.

## API + Risk Gate — FOUNDING PILOT

Current controlled machine packaging uses a **20,000-credit / 30-day** starting pool.

It can include:

- authenticated governed machine-readable data;
- country/corridor digests and profiles;
- signed Risk Objects;
- Risk Gate bundles;
- controlled API/export access for the agreed workflow.

Risk Gate remains non-authorizing. `execution_authorized=false` is the Geomacro boundary, and customer identity, permissions, policy, funds and downstream execution remain customer-controlled.

## Institutional — CONTRACTED DEPLOYMENT PATH

The current institutional starting model uses a **100,000-credit monthly starting pool**, followed by contracted volume and scope.

Potential contracted capabilities include:

- agreed countries, corridors and historical depth;
- higher API volume;
- structured exports;
- monitoring cadence;
- team/integration controls where implemented;
- support commitments only where operational evidence and the contract support them.

Institutional access does not imply a universal production SLA, unrestricted warehouse access or autonomous transaction authorization.

## Product-selection rule

A user should be able to understand the access ladder without knowing Geomacro's payment infrastructure:

1. **Use Free Explorer** to evaluate the public product.
2. **Use pay per call** when an AI agent needs an occasional governed answer after mainnet activation.
3. **Use Professional intelligence** when a person/team needs more history, attribution and workflow depth.
4. **Use API + Risk Gate** when software needs recurring governed machine access.
5. **Use Institutional** when scope, volume, controls and support need to be contracted.

The same safety and source-rights boundaries apply regardless of whether payment occurs through a subscription, invoice, x402 or another approved commercial rail.
