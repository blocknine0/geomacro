# 36. Arc Testnet

**Status: TECHNICAL PROOF · TESTNET**

Geomacro's onchain application layer currently operates on Arc Testnet.

Testnet technical proof includes areas such as:

- prediction-market contracts and lifecycle
- test-USDC interactions
- wallet flows
- Circle/CCTP-related implementation
- Bridge & Swap
- programmable transaction experiments

The intelligence architecture — GRI, structured intelligence, signed Risk Objects and Risk Gate — is positioned as a broader product layer and should not be described as Arc-dependent.

Arc Testnet proof demonstrates implementation capability. It is not equivalent to production mainnet deployment, real-money operation, external security certification or customer adoption.
