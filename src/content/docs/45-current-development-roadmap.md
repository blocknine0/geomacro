# 45. Current Development Roadmap

Geomacro's commercialization order is deliberately staged so public claims follow implementation evidence.

## Current hardening

- align website, repository and documentation as one source of truth
- complete GRI/data reliability and provenance controls
- harden Risk Object / Risk Gate contracts
- finish security, privacy and resilience evidence
- verify commercial source eligibility

## Next

- real staging HTTP/DB load evidence
- signing-key rotation/recovery drill
- remaining security remediation and re-test
- Early Access / Private Pilot package and pricing
- design-partner validation

## After product truth is stable

- permanent commercial demo
- reusable master pitch deck and audience variants
- paid pilot / recurring commercial validation
- broader production/mainnet integrations where justified

Permanent demo/deck creation is intentionally downstream of product, repo, website and security alignment so fundraising material does not become stale or overstate capability.
