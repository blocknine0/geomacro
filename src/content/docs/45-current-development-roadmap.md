# 45. Current Development Roadmap

Geomacro's commercialization order is deliberately staged so public claims follow implementation evidence and payment activation never outruns product, security or source-rights readiness.

## Shipped public foundation

- live Risk Intelligence;
- separate Geopolitical, Macroeconomic and Critical Minerals Risk Indices;
- Ask Geomacro;
- audited GRI v1.2 parent proof lineage and change-attribution foundation;
- public Research, Docs and trust/product-boundary surfaces.

## Current hardening

- keep website, repository, machine discovery and documentation as one source of truth;
- harden professional access, governed API delivery, signed Risk Objects and Risk Gate;
- complete commercial source-rights verification;
- finish security, privacy, resilience and production-database evidence;
- preserve the provider-wide real-funds lock while x402/mainnet adapters remain pre-launch;
- validate buyer/use-case packaging and design-partner workflows.

## Coordinated commercial launch

The next release phase is not simply "turn mainnet on". It requires the applicable gates to pass together:

- exact production deployment commit with required CI/security checks green;
- production credentials and dedicated receiving configuration;
- source-rights approval for the products being sold;
- production database/security readiness;
- explicit coordinated-launch and provider-specific real-funds authorization;
- capped first real-USDC purchase with settlement/delivery reconciliation;
- professional/API/institutional customer-use boundaries and support scope documented;
- marketplace listings published only after the actual paid service is live.

At that point Geomacro can deliberately move the prepared pay-per-call agent product from **MAINNET PRE-LAUNCH** to its verified live commercial state.

## After first commercial proof

- design-partner and paid-pilot validation;
- recurring subscription / API economics validation;
- permanent commercial demo and reusable pitch deck based on the verified product state;
- broader governed coverage and professional workflow features;
- additional marketplace/provider distribution;
- contractual service commitments only where operating evidence supports them.

## Permanent boundary

Prediction markets remain Arc Testnet-only and are not part of the production mainnet commercialization path. Risk Gate remains non-authorizing with `execution_authorized=false`; customer identity, permissions, policy, funds and downstream execution remain customer-controlled.
