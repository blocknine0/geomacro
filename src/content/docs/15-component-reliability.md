# 15. Component Reliability

The current public GRI v1.2 uses three scoring domains:

- geopolitics
- macroeconomics
- rare earth / critical-mineral risk

Each domain has an equal base weight of `1/3` when it has eligible evidence.

A missing domain is **excluded**, not assigned a synthetic score of zero. Active domain weights are renormalized and evidence coverage is disclosed separately.

For each published snapshot, Geomacro can expose evidence-quality context such as:

- active domains
- coverage
- source count
- independent-story count
- weighted confidence
- evidence contributions
- verification status

This keeps the score separate from the strength and breadth of the evidence supporting it.

Crypto remains part of the broader Geomacro technical/data architecture but is **not a GRI v1.2 scoring domain**.
