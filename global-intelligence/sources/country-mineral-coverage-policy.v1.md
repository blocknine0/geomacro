# Country × Mineral Coverage Policy

The global intelligence mineral layer uses the canonical Geomacro 195-country registry as the only valid country universe.

Rules:
- A country is valid only when its ISO3 exists in the canonical registry.
- Three-letter strings are not automatically accepted as valid country IDs.
- Unknown aliases remain unresolved.
- Unresolved country rows never become certified country evidence.
- Coverage is measured against all 195 canonical countries.
- Missing evidence is reported as a gap, never as zero.
- Commodity normalization is separate from country normalization.
- A resolved country does not imply that a commodity is valid.
