# Free Source Priority

## Priority 1: implement first
- GDELT V2 / GAL for geopolitics.
- World Bank Indicators for macro baseline.
- USGS MCS / minerals data for critical-minerals baseline.
- Official national sources for country-level primary evidence.
- Telegram API/TDLib for low-latency source collection.

## Priority 2: add redundancy
- UN Comtrade free API key.
- IMF SDMX.
- Eurostat.
- BIS public datasets.
- ReliefWeb for humanitarian/geopolitical context.
- Additional official international and national feeds.

## Priority 3: evaluate only if they materially improve coverage
- JRC RMIS.
- IEA critical-minerals datasets.
- commercial providers with genuinely usable free access.

## Principle
Do not add a source just to increase source count. Add it when it improves authority, geographic coverage, freshness, redundancy, or verification quality.
