# 585-Cell Certification

Certification must prove, not assume:

1. 195 canonical countries exist.
2. Every country has all three category cells.
3. Every cell has an enabled source mesh.
4. Each cell has recent successful ingestion.
5. Telegram sources are separately health-checked.
6. Authoritative Telegram sources have identity metadata.
7. Cross-source verification is operational.
8. Conflicting evidence is surfaced rather than silently merged.
9. Early signals remain distinct from confirmed intelligence.
10. Router and structured answer contracts pass tests.

GLOBAL_INTELLIGENCE_V1 = CERTIFIED

is permitted only after all gates pass.
